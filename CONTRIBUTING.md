# Editing the Tabletop MRI wiki

The public site mounts `content/` at `/tabletop-mri/` and `wiki_files/`
at `/tabletop-mri/files/`.

- Put each page in `content/<page-slug>/index.md`.
- Use `content/_index.md` only for the `/tabletop-mri/` landing page.
- Link to downloads with `/tabletop-mri/files/<filename>`.
- Use root-relative links for other group wikis.
